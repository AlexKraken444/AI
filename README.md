# Kraken Context 2

## Обучение языку с нуля на GPU

Добавлен отдельный двухэтапный процесс: предварительное обучение на русском
тексте Wikipedia и последующее обучение диалогам на собственных весах.
Поддерживаются CUDA, накопление градиентов, mixed precision и возобновление.
Это развитие обучения, **не заявление об исправленном качестве чата**:
опубликованные маленькие модели всё ещё могут отвечать бессвязно.
Команды, ограничения и происхождение данных: [обучение с нуля](training/SMALL_MODEL.md).

## Новое обучение: Context 3

В меню модели добавлен отдельный режим **Context 3 — обучение на диалогах**. Он обучен с нуля на 17 880 пригодных для текущей длины последовательности примерах: 240 отфильтрованных русских диалоговых примеров OpenAssistant и 17 640 авторских примеров и задач. Это **не 18 тысяч реальных разговоров**. Подготовлено 18 152 обучающих записи; 272 слишком длинных ответа исключены без обрезания.

Архитектура: 1 839 040 параметров, три слоя, четыре головы внимания, ширина 160, собственный BPE-токенизатор на 3 072 токена, общий контекст 512 токенов. При обучении выполнено 3 200 шагов; выбран checkpoint шага 400 с лучшим результатом на validation. Поздние варианты переобучались. PyTorch/NumPy-инференс выбранных весов численно сопоставлен.

Сравнение на заранее отделённых новых задачах (точное совпадение с заданным ответом):

| Проверка | Context 2 | Context 3 |
| --- | --- | --- |
| Кто что любит | 19/60 | 25/60 |
| Исправление старого факта | 0/60 | 31/60 |
| Отсутствующий факт | 0/12 | 11/12 |

На 40 отложенных диалоговых примерах OpenAssistant отрицательное лог-правдоподобие одинаковых префиксов ответов на UTF-8 байт снизилось с 5.6502 до 1.4261. Это показатель предсказания текста, **не оценка истинности или качества общения**. Свободные ответы могут быть бессвязными и хуже прежних на знакомых темах. Поэтому Context 3 включается пользователем отдельно; default остаётся Context 2.

[Описание источников и подготовки данных](training/DATA_CARD.md), [результаты сравнения](training/comparison.json), [точные ревизии и контрольные суммы](training/data_manifest.json).

Скрипт обучает кандидата в `training-output/` и не перезаписывает рабочую модель. Новые поставленные веса — `neural/checkpoint3/`. Данные и обучающие зависимости исключены из пакета Vercel.

## Обновление: Transformer и память

Теперь по умолчанию работает **собственный генеративный Transformer**, обученный с нуля: 781 568 параметров, 3 слоя, 4 головы внимания, ширина 128, контекст вместе с ответом — 384 токена. Веса случайно инициализированы, готовые языковые модели и внешние AI API не используются. Архитектура написана в `train_transformer.py`; PyTorch считает градиенты при обучении. На Vercel работает отдельный NumPy-инференс с KV-кешем и настоящей передачей генерируемых токенов.

**Качество экспериментальное:** модель иногда путает участников, факты и смысл незнакомых формулировок. Внимание учитывает порядок токенов, но это не доказательство человеческого понимания или полноценного рассуждения. Режим Mini с подготовленными ответами сохранён в меню модели. Калькулятор и точное извлечение личных фактов работают программно.

### Память

- Явные факты («Меня зовут Алекс», «Я изучаю Python», «Запомни: …») сохраняются между чатами в localStorage этого браузера.
- Уже существующая история мигрируется без удаления чатов. Поиск находит связанные старые сообщения и передаёт ограниченное число фрагментов серверу.
- Раздел **Память** позволяет просмотреть и забыть факты, исключить отдельные чаты, отключить память или очистить её целиком.
- Ответ показывает использованные источники. Новое значение имени заменяет старое; удалённый факт не восстанавливается из того же старого сообщения.
- Очистка памяти не удаляет сами чаты. Сообщения текущего диалога остаются его контекстом. Память не синхронизируется между устройствами; посетители сайта не разделяют общую память.
- Сервер не сохраняет переданные записи, не обучается на них и не смешивает данные разных запросов. Хостинг может вести технические журналы.

## Архивное описание Mini 1

Русскоязычный чат в стиле ChatGPT: тёмный адаптивный интерфейс, серые статусы обработки, белые ответы, история диалогов и мягкий сарказм. Подготовлен для Vercel; внешние AI API и ключи не нужны.

**Важно:** это работающий учебный нейросетевой ассистент, а не аналог GPT по возможностям. Собственная MLP распознаёт одну из 18 тем и выбирает подготовленный ответ. Она не генерирует произвольный текст и не умеет полноценно рассуждать. Серые реплики — статусы и стилизованные комментарии, а не скрытые мысли модели. Нет доступа к интернету, исполнения пользовательского кода или автоматического самообучения.

## Собственная нейросеть

- Признаки: нормированные хешированные слова и символьные триграммы, 384 измерения.
- Архитектура: Dense(384, 48) → tanh → Dense(48, 18) → softmax.
- 19 362 обучаемых параметра, случайная инициализация с seed 42.
- Прямой проход, обратное распространение ошибки, cross-entropy с L2-регуляризацией и Adam написаны в `train.py` вручную. NumPy выполняет только матричные операции; PyTorch, TensorFlow и готовые веса не используются.
- 146 авторских обучающих фраз в `neural/intents.json`. Обученные веса находятся в `neural/weights.json`.
- Инференс реализован на стандартном Python в `neural/network.py`.
- Низкая уверенность или недостаточное сходство с примерами приводят к ответу «не знаю». Пороги эвристические; уверенность softmax не является гарантией правильности.
- Точность на обучающих примерах не показывает качество на произвольных вопросах. В тестах есть небольшой отдельный набор перефразировок и неизвестных тем; это регрессионная проверка, не полноценный бенчмарк.

Калькулятор, запоминание имени и повтор предыдущего ответа реализованы отдельными программными обработчиками. Калькулятор разбирает ограниченный AST, не использует `eval` и не исполняет код. Модель получает до 24 последних сообщений; произвольный контекст диалога не понимает.

## Интерфейс и данные

- Новый чат, переключение и удаление диалогов; до 50 чатов по 100 пар сообщений.
- История и переключатель характера сохраняются в localStorage. На общем компьютере история видна другим пользователям того же браузера.
- Enter отправляет сообщение, Shift+Enter добавляет строку, Ctrl/Cmd+K создаёт новый диалог.
- Поток NDJSON передаёт `status`, `token`, `done` и `error`. Ответы короткие и часто завершаются почти мгновенно; скорость потока зависит от буферизации хостинга.
- Есть остановка запроса, повтор, копирование, ошибки сети и таймаут 30 секунд.
- Текст пользователя и модели отображается через `textContent`; HTML не исполняется.
- Для ответа серверу передаются последние сообщения. Приложение не хранит переписку на сервере, но хостинг может вести технические журналы.
- Подготовленная база ответов не содержит вредных инструкций. Дополнительная проверка опасных запросов эвристическая и не является универсальной системой модерации. При расширении базы проверяйте её содержимое.
- Публичный API без аккаунтов. Есть ограничения размера запроса, но нет распределённого rate limiting; для большого публичного запуска настройте лимиты в Vercel Firewall.
