# Kraken — собственная экспериментальная нейросеть

Активный сайт использует только наши веса Context 4, обученные с нуля: 15,36 млн параметров, собственный BPE, 6 слоёв Transformer. Чужие модели и AI API не вызываются. Python-инференс работает на Vercel: включённый компьютер и туннель для ответов не нужны.

**Качество свободного разговора пока неудовлетворительное.** Модель может выдавать бессвязный текст. Возврат собственных весов не означает исправления качества. Mini — отдельный справочник, а не генеративный ИИ.

Предыдущий вариант использовал открытые веса Qwen с согласия пользователя; по новому требованию он отключён в интерфейсе и API. Незавершённый переход на WebLLM также отменён. Исходники прежнего GPU-подключения остаются в истории проекта, но не используются активным маршрутом ответов.

## Запуск

```sh
python -m pip install -r requirements.txt
python dev.py
```

## Обучение и проверки

[Описание собственного обучения](training/SMALL_MODEL.md). [Честные примеры качества](training/context4_review.json). Новые веса нельзя считать улучшенными только по уменьшению ошибки обучения: нужны проверки свободных ответов и смены темы.

[Последнее дообучение и сравнение ответов](training/reviews/topic-switch-v1/README.md): 2 000 шагов снизили ошибку предсказания токенов, но кандидат не прошёл проверку свободных ответов. На сайте эти веса не установлены.

```sh
python -m unittest discover -s tests
node --test tests/*.test.cjs
```

История и память сохраняются в браузере. Для генерации выбранные сообщения передаются Python-функции сайта. Серые сообщения — статусы обработки, не скрытые мысли.

## Проверенные факты

Отдельный справочный обработчик распознаёт варианты вопроса об имени президента России, включая некоторые очевидные опечатки. Он показывает официальный источник и дату проверки. Это ограниченная справочная функция, не результат понимания Transformer и не поиск всего интернета. Прочие ответы модели по-прежнему ненадёжны.
