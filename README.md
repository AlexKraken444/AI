# Kraken · Qwen3 на собственном GPU

Разговорный сайт на Python с открытыми весами **Qwen3 4B Q4_K_M**, выполняемыми через llama.cpp на компьютере владельца. Vercel обслуживает интерфейс и Python-прокси; GPU на Vercel не требуется. Платные AI API не используются. **Веса Qwen обучены авторами Qwen, не нами с нуля.**

Последний вопрос передаётся модели последним, предыдущие сообщения сохраняют роли и порядок. При сокращении контекста удаляются самые старые сообщения, а новый вопрос остаётся целиком. Ответы не кешируются между запросами. Если GPU выключен, сайт показывает ошибку, а не переключается незаметно на старую модель.

## Запуск

См. [GPU_SETUP.md](GPU_SETUP.md): загрузка файлов, локальный запуск, подключение Vercel и перезапуск туннеля.

```powershell
python -m pip install -r requirements.txt
python run_gpu.py
```

Открыть http://127.0.0.1:8000/. Ctrl+C останавливает процессы, запущенные скриптом. Компьютер должен оставаться включённым для работы опубликованного сайта.

## Память и обработка

История и сохранённые факты остаются в localStorage этого браузера. Подходящие записи передаются серверу вместе с текущим диалогом; обучение на личной переписке автоматически не выполняется. Новый выбор модели не удаляет память или чаты. Серые сообщения обозначают этапы обработки, а не скрытые мысли.

## Проверки

```powershell
python -m unittest discover -s tests
node --test tests/models.test.cjs tests/memory.test.cjs
```

Синтетический разговор на реальной RTX 4060 проверен: приветствие → Python → столица Франции → уточнение языка → 2+2. Результаты: [training/gpu_conversation_check.json](training/gpu_conversation_check.json). Это небольшая функциональная проверка, не доказательство безошибочности модели.

Прежние модели Context 2–4, обученные с нуля, оставлены в меню как архивные эксперименты. Их ограничений и бессвязных ответов дальнейшее короткое обучение не устранило. История обучения: [архив README](training/ARCHIVE_README.md).
