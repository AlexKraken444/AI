# Запуск Qwen3 на Windows / RTX 4060

## Уже подготовленный компьютер

Файлы находятся в `.local-models/` и `.local-runtime/llama/`. Запусти:

```powershell
python -m pip install -r requirements.txt
python run_gpu.py
```

Сайт: http://127.0.0.1:8000/. GPU API слушает только `127.0.0.1:8081` и требует ключ из `.gpu-state/api-key`. Ключ создаётся автоматически, не выводится в консоль и не попадает в Git. Логи находятся в `.gpu-state/`.

Для Python из Codex вместо `python` можно использовать:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" run_gpu.py
```

Если серверы уже запущены, второй экземпляр не нужен. Ctrl+C в окне запуска останавливает его дочерние серверы. Фоновый запуск, выполненный помощником, можно остановить через диспетчер задач: `llama-server.exe` и соответствующий процесс `run_gpu.py`. После перезагрузки компьютера запуск повторяется.

## Чистая установка

Требуются Windows x64, современный драйвер NVIDIA, Python 3.10+ и свободное место около 4 ГБ.

1. Создай `.local-models` и `.local-runtime/llama` в папке проекта.
2. Скачай [официальные веса Qwen3 4B Q4_K_M](https://huggingface.co/Qwen/Qwen3-4B-GGUF/resolve/bc640142c66e1fdd12af0bd68f40445458f3869b/Qwen3-4B-Q4_K_M.gguf) в `.local-models/Qwen3-4B-Q4_K_M.gguf` (2 497 280 256 байт).
3. SHA256 файла должен быть `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`. Проверить: `Get-FileHash .local-models/Qwen3-4B-Q4_K_M.gguf -Algorithm SHA256`.
4. Распакуй [llama.cpp b11138 CUDA 12.4](https://github.com/ggml-org/llama.cpp/releases/download/b11138/llama-b11138-bin-win-cuda-12.4-x64.zip) в `.local-runtime/llama`, чтобы `llama-server.exe` находился прямо в этой папке.
5. Если нет CUDA DLL от ранее установленного PyTorch в `.training-libs/torch/lib`, распакуй [официальные CUDA runtime DLL](https://github.com/ggml-org/llama.cpp/releases/download/b11138/cudart-llama-bin-win-cuda-12.4-x64.zip) в ту же папку движка.
6. Выполни команды запуска выше. Веса Qwen распространяются авторами на условиях Apache 2.0; описание и лицензия — в [репозитории Qwen](https://huggingface.co/Qwen/Qwen3-4B-GGUF).

## Подключение Vercel

GitHub хранит код. Vercel запускает Python-прокси, но не GPU-модель. Компьютер владельца должен работать и иметь защищённый HTTPS-адрес для API модели.

В **Settings → Environment Variables** существующего проекта Vercel добавь:

- `GPU_CHAT_URL`: HTTPS-адрес туннеля/сервера без `/v1/chat/completions` в конце.
- `GPU_CHAT_KEY`: содержимое локального `.gpu-state/api-key`.

Затем выполни Redeploy. Эти значения предназначены только серверу, не JavaScript браузера. Образец без секретов — `.env.example`. Не публикуй `.gpu-state`, ключи или логи.

### Работающий вариант: localhost.run

На текущем компьютере Cloudflare не соединяется. С разрешения владельца используется HTTPS/SSH-туннель localhost.run. Посредник обрабатывает тексты запросов и ответов; API модели требует секретный ключ.

Оставь `run_gpu.py` работающим и во втором терминале запусти:

```powershell
ssh -T -o ServerAliveInterval=30 -R 80:127.0.0.1:8081 nokey@localhost.run
```

SSH покажет HTTPS-адрес вида `https://....lhr.life`. Передай его в `GPU_CHAT_URL` в Vercel и выполни Redeploy. При первом соединении SSH попросит подтвердить ключ сервера; проверяй, что подключаешься именно к `localhost.run`. Не отключай проверку ключа сервера.

Это временный адрес: после разрыва или перезапуска туннеля он может измениться. Постоянный адрес потребует отдельной настройки у провайдера. Текущий туннель запущен в фоне; его PID записан в `.gpu-state/ssh-tunnel.pid`. Не закрывай соответствующий процесс `ssh.exe`, пока сайт должен отвечать.

Временный Cloudflare Tunnel можно запустить официальным `cloudflared`:

```powershell
cloudflared tunnel --url http://127.0.0.1:8081 --protocol http2
```

Скопируй полученный HTTPS-адрес в `GPU_CHAT_URL`. Quick Tunnel меняет адрес после перезапуска и предназначен для тестирования; для постоянной работы нужен туннель с постоянным адресом. Quick Tunnel не поддерживает SSE, поэтому адаптер запрашивает у него целый ответ JSON; локально и через обычный сервер токены передаются потоком.

Ошибки `lookup ... no such host` и `TLS handshake ... EOF` относятся к сети между компьютером и Cloudflare, а не к весам модели. Не отключай проверку сертификатов. Альтернативного посредника следует подключать с учётом того, что он обрабатывает тексты диалогов.

## Ограничения

- Контекст запуска — 8192 токена, ответ — до 512 токенов; слишком старая история сокращается. Память добавляет выбранные записи, а не все чаты целиком.
- Модель может ошибаться. Пять успешных реплик в проверке не заменяют оценку на большом наборе задач.
- На личной переписке автоматическое обучение не выполняется. Загрузка готовых весов — не дополнительное обучение.
- Если GPU или туннель выключен, сайт честно покажет ошибку. Перехода на старую бессвязную модель нет.
