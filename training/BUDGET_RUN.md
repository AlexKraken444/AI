# Ограниченный запуск: 30 минут обучения

Цель — проверить, насколько собственный Transformer со случайной инициализацией
можно улучшить на RTX 4060 Laptop GPU за ограниченное время. Готовые веса,
чужой токенизатор и внешние модельные API не используются.

## Фактический результат

Обучающие сессии заняли **1804,06 секунды** (30 минут 4 секунды), включая
промежуточные сохранения. Предобучение: 6721 шаг, 110 116 864 посещения токенов,
validation NLL 9.1339 → 3.4090. SFT: 4000 шагов, 10 760 456 токенов ответов,
validation NLL 3.8269 → 2.4576. Это разные распределения данных; показатели
двух этапов не являются общей шкалой качества разговора.

**Полноценный разговорный ИИ за этот запуск не получился.** В ручном просмотре
16 сырых ответов удовлетворительными оказались 4: три приветствия и короткое
прощание. Остальные 12 не выдержали проверку смысла/фактов, включая арифметику.
Например, модель путает столицу Франции с Италией и неправильно объясняет таяние
льда. Два успешных точных вопроса присутствовали в SFT train, другие два — нет.
Это ограниченная проверка с раскрытием знакомых примеров, не независимый широкий
бенчмарк и не основание заявлять о надёжном понимании языка.

В приложении `2+2 Сколько` получает `2+2 = 4` **от калькулятора**; непосредственно
новый Transformer ответил `1.`. Эти результаты намеренно не смешиваются.
Context 4 опубликована как новый экспериментальный вариант с видимым указанием
ограничений. История и память сохраняются при переходе на неё.

[Все сырые ответы старой и новой моделей](context4_review.json),
[метрики, хеши и происхождение данных](context4_training.json).
Проверены 39 Python-тестов, 12 JS-тестов и 3 отдельные интеграционные проверки
обучения. Экспорт PyTorch → NumPy прошёл численное сравнение. Эти тесты проверяют
работоспособность и конкретные регрессии, а не общую правильность ответов.

## Данные и атрибуция

* Язык: [Wikimedia Wikipedia](https://huggingface.co/datasets/wikimedia/wikipedia),
  `20231101.ru`, ревизия `b04c8d1ceb2f5cd4588862100d08de323dccfbaa`,
  CC-BY-SA-3.0 / GFDL. Использован фиксированный префикс из **71 135 516**
  токенов подготовленного train-потока. Отдельные validation/test-документы
  содержат 2 289 029 / 1 991 783 токена. Атрибуция статей (URL, название, ID)
  сохранена в локальных исходных JSONL. Это часть одного раздела снимка,
  а не вся русская Wikipedia.
* Инструкции: [RuTurboAlpaca, Ilya Gusev и участники](https://huggingface.co/datasets/IlyaGusev/ru_turbo_alpaca),
  ревизия `460b1f3312aa21ef774e916e532a9576f7938a0d`, CC-BY-4.0.
  Это синтетические пары, сгенерированные ChatGPT авторами корпуса.
  Их использование как учебного текста не означает загрузку весов ChatGPT.
  Исключены 901 пример с негативными оценками, пустые/слишком длинные записи,
  адреса электронной почты и найденные дубликаты. Неоценённые записи не прошли
  независимую ручную проверку; ошибки в исходных ответах остаются возможными.
* Дополнительно: ранее подготовленные русские диалоги
  [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1),
  Apache-2.0, и авторские примеры приветствий, прощаний и благодарностей.
  Эти реплики используются **в обучении весов**, не как таблица ответов
  нового генератора. Поэтому точное совпадение тестового вопроса с учебным
  примером отдельно помечается в отчёте; оно не доказывает обобщение.

Всего после объединения: 26 882 train, 1 500 validation, 1 444 test примера.
Для контекста 512 сохранены 26 742 / 1 496 полных train/validation примеров.
Длинные вопросы с ответами исключаются целиком. Разделение и удаление точных
дубликатов выполняются до обучения; близкие смысловые дубликаты могут оставаться.

## Воспроизведение

Сначала подготовить исходный текст командой `training/prepare_language.py`
из [основной инструкции](SMALL_MODEL.md). Префикс ранее прерванной токенизации
можно использовать, только если в нём есть минимум 71 135 516 полных uint32
токенов и тот же токенизатор. Это новый ограниченный набор с собственным manifest.

```bash
python training/prepare_budget.py
python training/scratch.py --stage pretrain --data training-data/language-budget --output training-output/language-30min --device cuda --steps 8000 --batch 4 --accumulate 8 --eval-every 500 --eval-batches 20 --max-seconds 1200
python training/scratch.py --stage sft --data training-data/dialogue-budget --initialize training-output/language-30min --output training-output/dialogue-30min --device cuda --steps 4000 --batch 4 --accumulate 8 --lr 0.0001 --basic-fraction 0.1 --eval-every 250 --eval-batches 20 --max-seconds 600
python training/review_candidate.py --candidate training-output/dialogue-30min --output training-output/review-30min.json
```

При остановке по времени обучение может закончиться раньше указанного числа
шагов. Подготовка данных, начальная validation, финальное сохранение и сравнение
экспорта занимают дополнительное время. Для повторного нового запуска нужны
пустые output-каталоги; `--resume` продолжает существующее состояние.

На SFT с вероятностью 0.1 учебная строка выбирается из авторских основ разговора,
иначе — из всего train. Это увеличивает число градиентных обновлений на коротких
репликах, которые иначе теряются среди длинных заданий. Validation не меняет
распределение примеров и не применяет эту дополнительную выборку.

Проверка ответов идёт напрямую через `Transformer.generate`: без калькулятора,
памяти и классификатора справочных ответов. Проверка приложения проводится
отдельно — например, распознавание `2+2 Сколько` является исправлением маршрута
калькулятора и не выдаётся за приобретённый моделью навык арифметики.

Падение token NLL само по себе не считается исправлением качества чата.
Решение о публикации принимается после просмотра сырых ответов и новых вопросов.
